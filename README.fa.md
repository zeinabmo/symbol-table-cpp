# جدول نمادها (Symbol Table) با C++

🇬🇧 [English version](README.md)

یک جدول نمادها که با **جدول هش و روش زنجیره‌ای (chaining)** ساخته شده است؛ یعنی هر خانه از جدول یک لیست پیوندی دارد.
این پروژه یک تمرین درس ساختمان داده است.

## امکانات

- افزودن نماد (نام و نوع)؛ نام تکراری پذیرفته نمی‌شود
- جستجو، حذف و نمایش کل جدول
- مدیریت ورودی نامعتبر و آزادسازی کامل حافظه در پایان برنامه

## نحوه کار

- اندازه جدول عمداً ۳ است تا برخورد (collision) راحت دیده شود.
- تابع هش: طول نام تقسیم بر ۳ و باقیمانده آن، یعنی `name.length() % 3`
- هر خانه یک لیست پیوندی از گره‌هایی به شکل `node { name, type, next }` است.

## ساخت و اجرا

```bash
g++ -std=c++17 -o symboltable src/main.cpp
./symboltable        # on Windows: symboltable.exe
```

## نمونه خروجی

```
Bucket 0: pencil (int) -> animal (string)
Bucket 1: x (int)
Bucket 2: Empty
```
